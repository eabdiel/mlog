# Mlog — Rails microblog prototype 

Legacy Ruby on Rails microblog administration prototype based on Michael Hartl’s Rails Tutorial sample application.

A project of **[ProgreTech LLC](https://progretech.com)**, owned and maintained by **Ed Rodriguez**. Third-party components and contributions retain their respective ownership and notices.

[Project website](https://progretech.com) · [Report an issue](https://github.com/eabdiel/mlog/issues) · [Contribute](CONTRIBUTING.md)

Based on the microblogging sample_app created by Michael Hartl on his "Ruby on rails tutorial : learn rails by example"
Mlog xD will be the administrative site that will ultimately control the functions of the future mobile
application.  
The site is designed to act as the main database for every mobile blogger.
